# Upcoming Payments Carousel — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the vertical upcoming payments list with a horizontally scrollable shadcn Carousel of portrait cards on the Overview page.

**Architecture:** Three surgical changes — install the shadcn `carousel` component, rewrite `UpcomingPaymentsList.tsx` internals to use it, and add `overflow-visible` to the `SectionCard` wrapper in `OverviewPage` so the peek card isn't clipped. The component's public interface (`UpcomingItem`, props) is unchanged.

**Tech Stack:** React 19, TypeScript (strict), Tailwind CSS v4, shadcn/ui, embla-carousel-react

**Spec:** `docs/superpowers/specs/2026-03-21-upcoming-payments-carousel.md`

> **Note:** No test suite exists. Verification is manual via `npm run dev` in the browser.

### Task 2: Rewrite UpcomingPaymentsList as a carousel

**Files:**
- Modify: `src/components/UpcomingPaymentsList.tsx`

- [ ] **Step 1: Replace the file contents**

  Open `src/components/UpcomingPaymentsList.tsx` and replace it entirely with:

  ```tsx
  import { Avatar, AvatarFallback, AvatarImage } from '@/components/ui/avatar'
  import { DaysBadge } from '@/components/DaysBadge'
  import { formatCurrency } from '@/lib/constants'
  import {
    Carousel,
    CarouselContent,
    CarouselItem,
  } from '@/components/ui/carousel'

  export interface UpcomingItem {
    id: string
    name: string
    days: number
    next: Date
    amount: number
    icon_url: string | null
  }

  interface UpcomingPaymentsListProps {
    items: UpcomingItem[]
  }

  export function UpcomingPaymentsList({ items }: UpcomingPaymentsListProps) {
    return (
      <Carousel
        opts={{ align: 'start', dragFree: true }}
        className="px-4 py-3"
      >
        <CarouselContent className="-ml-3">
          {items.map(({ id, name, days, next, amount, icon_url }) => (
            <CarouselItem key={id} className="pl-3 basis-1/2 sm:basis-1/3">
              <div className="border rounded-lg p-3 flex flex-col items-center gap-2 min-h-[140px]">
                <Avatar size="md">
                  {icon_url && <AvatarImage src={icon_url} />}
                  <AvatarFallback>{name[0]?.toUpperCase()}</AvatarFallback>
                </Avatar>
                <p className="text-sm font-medium text-center truncate w-full">{name}</p>
                <p className="text-xs text-muted-foreground text-center">
                  {next.toLocaleDateString('bg-BG', { day: 'numeric', month: 'short', year: 'numeric' })}
                </p>
                <div className="flex flex-row items-center justify-center gap-2 mt-auto">
                  <span className="text-sm tabular-nums">{formatCurrency(amount)}</span>
                  <DaysBadge days={days} />
                </div>
              </div>
            </CarouselItem>
          ))}
        </CarouselContent>
      </Carousel>
    )
  }
  ```

  Expected: zero TypeScript errors. If TypeScript complains about `Carousel` exports not found, verify `src/components/ui/carousel.tsx` was created in Task 1.

### Task 3: Fix overflow clipping on OverviewPage

> **Note:** The spec's Scope section says `OverviewPage` is unchanged, but this was superseded by the spec's own Overflow Clipping section and Files Changed table. This task is required — skipping it will clip the carousel's peek card.

`SectionCard` applies `overflow-hidden` unconditionally. Without this fix, the partial-peek card on the right edge is clipped.

**Files:**
- Modify: `src/pages/OverviewPage.tsx`

- [ ] **Step 1: Add `overflow-visible` to the SectionCard**

  In `src/pages/OverviewPage.tsx`, find the `SectionCard` that wraps the upcoming payments:

  ```tsx
  <SectionCard title="Предстоящи плащания">
    <UpcomingPaymentsList items={upcoming} />
  </SectionCard>
  ```

  Change it to:

  ```tsx
  <SectionCard title="Предстоящи плащания" className="overflow-visible">
    <UpcomingPaymentsList items={upcoming} />
  </SectionCard>
  ```

- [ ] **Step 2: Verify the build is clean**

  ```bash
  npm run build
  ```

  Expected: zero TypeScript errors.

- [ ] **Step 3: Start the dev server and verify in the browser**

  ```bash
  npm run dev
  ```

  Open the Overview page and check:
  - [ ] The upcoming payments section shows portrait cards in a horizontal row
  - [ ] ~2 cards visible on a narrow window, ~3 on wider — with a partial peek of the next card on the right
  - [ ] Each card shows: avatar/logo, subscription name, next payment date (in Bulgarian), amount, and days badge
  - [ ] Dragging/swiping horizontally scrolls through the cards
  - [ ] The peek card is not clipped (no hard right edge cutting it off)
  - [ ] "Today" or ≤3 days badges appear red, ≤7 days secondary, later as outline
  - [ ] Subscriptions with no `icon_url` show the first letter of the name as fallback
